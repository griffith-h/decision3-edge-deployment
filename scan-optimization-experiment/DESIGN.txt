实验目标与验收

在桥接融合＋同层投影并行组合候选上，只修改 CPU GatedDeltaNet 扫描。
保留官方模型版本、12层、权重、完整注意力的非因果 mask、GatedDeltaNet 的因果递推。
不反编译，不构建镜像，不替换/停止/重配线上三线程容器。

候选：
1. compact：短序列使用真实长度的一个 chunk，去掉填充和零初始状态下无用的跨 chunk 状态计算。
2. native：按公开 Transformers Qwen3.5 逐 token 公式执行 FP32 状态递推；按 head 和 value 列分块，用自写 NEON/OpenMP 内核减少临时张量和调度。
   S <- exp(g_t) S
   delta <- beta_t (v_t - k_t^T S)
   S <- S + k_t delta^T
   o_t <- q_t^T S
   保留原 FP32 q/k L2 归一化和 query 缩放，输出仍在原位置转 BF16。

原生内核只处理 CPU BF16、1..512 token、匹配的头维度、零初始状态、不返回状态的调用。
compact 单 chunk 候选仍限1..128 token；长输入交给原先多 chunk 实现。
use_cache=False 是调用元数据；cu_seqlens 非空、其他未知非空参数、状态输入、长序列和不支持的形状/类型均交给既有扫描。
短序列限制是优化路径范围，不是裁剪或丢弃输入 token。

状态每次调用、每个工作块独占并初始化为零；C 不持有 Tensor 指针，不保留跨请求状态。
OMP_NUM_THREADS=3、OMP_THREAD_LIMIT=3、CPU4..7，与组合基线一致；NPU桥接不改。

验证顺序：
- 实际115token请求捕获6层扫描输入，检查优化路径命中，再微测扫描速度和数值误差。
- 最小边界检查：官方递推公式对照、两个归一化设置、非连续输入、值维度尾部、长度边界、输入不被修改、因果前缀、跨请求隔离、回退透传。
- 同一已加载模型、同一个78句柄组合引擎，只切换扫描函数；7用例14问题比较，概率/score/noul最大绝对差<=0.01，choice一致；排除confidence和legend。
- 交替顺序12轮，每组预热1次，每个计时输出都校验；合格最快候选再100次并逐次检查输出。
- 扫描边界轻量计时区分扫描与其余部分；不把 profiler 运算符耗时相加冒充无插桩端到端时延。
- 前后校验线上容器ID、启动时间、配置、源码哈希、健康与示例响应，结束后临时容器移除。

性能口径：独立进程，预热后完整 system_one 调用，并发1，固定115token单问题，排除模型加载、HTTP、网络。
微测和端到端测量分别报告。短测试与少量用例不能证明长期硬时限或完整数据集准确率。
